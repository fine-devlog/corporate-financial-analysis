# 企業データ分析に関するアンケート

## survey_app
アンケートツールの完成版の<a href="https://corporate-financial-analysis-o9nbqdyy6ypyienfeu4ymp.streamlit.app/">link</a>はここです

## feelings（完成形のアンケートに関する振り返り）
会社四季報と就職四季報を就活で利用したか、という質問に、「どちらも利用した」「就職四季報のみ利用した」と回答した人に「会社四季報をどのように利用しましたか」という質問が表示されるようになってしまっていた。
UIは質問と回答が区別されづらくなっており、使いづらいという。google formでは質問は太字で回答するところは細字になっているのでわかりやすい。
スマホだとタイトルの字はでかすぎる。逆に質問のとこの字は小さすぎる。
自分の開発に興味を持ってもらうきっかけとして、今回のアンケートはかなり有効な手段だった。
PythonでWebのようなものが作れるという点に驚く人が多かった。

## result（アンケートを通しての学び）
四季報が注目されたのは５年近く前の就活市場で、今はAIを利用した企業分析と自己分析が主流。わざわざ四季報を読めるようになっても、四季報に記載されている情報だけでは足りないことが多い。そして就活生に有償の商品を販売するよりもアフィリエイトのように広告を載せることで企業からお金をもらうという形式の方が簡単に収益化が目指せる。AIが主流の現代の就活市場において価値を感じてもらうにはどうすればいいのか。また、就活生では広すぎるので、大学何年生のどんな性格の何を目指す人向けに作りたいのかを明確にすることが必須。
個人開発を始めたばかりで周りの意見に流されることが多いが、自分はどのような人生を送りたくて、どのような形でお金をもらいたくて、そのためにどうしていけばいいのかという自分自身の軸も模索していくべきだと痛感した。
