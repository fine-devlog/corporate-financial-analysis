# 様々な回答書式とデータ保存機能を搭載したサンプルアンケート
## 概要
アンケート作成に必要な様々な回答書式のサンプル、管理者専用閲覧ページ、入力されたデータの保存機能を搭載したアンケートプログラム。

## 使い方
以下のURLをクリックしてstreamlit cloudからお試しください。
管理者専用ページはパスワードがないと開けないので、ご覧になれない仕様となっています。
https://corporate-financial-analysis-n4uuxy8yxq8whj84ry3vui.streamlit.app

## 目的
就活生の方や就活を経験した方に、企業データの利用に関するアンケートに回答していただき、今後のツール作成の方向性を決めていこうと考えている。
その調査用のアンケートの作成に向け、回答書式のコマンドの書き方や、使用感、保存機能のライブラリの使い方、管理者専用閲覧機能のつけ方、Excelファイルとしてダウンロードするためのコードの組み方を把握した。
これから、質問の内容が確定し次第、実際に使うアンケートプログラムの作成に取り掛かる予定。

## 感想
streamlitやpandasは今までのプログラムで利用してきたが、今回初めてsupabaseを使った。
コードをAIに任せてしまっている分、エラーの原因と直し方の把握に時間がかかり、別の場所のエラー発生に対して予測ができない。
エラーの内容を読んですぐ原因を把握できるよう、英語に慣れておきたい。
私は今のままではプログラミングができるとは言えないので、まずサンプルを作ってから作りたいものに合わせてサンプルからコマンドを引用してプログラムを組むというこのスタイルでコーディングを練習していき、ライブラリの使い方に慣れていきたい。
